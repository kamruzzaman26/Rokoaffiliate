একসাথে অনেক অ্যাফিলিয়েট লিংক তৈরি করুন

রকমারির প্রোডাক্ট ও বইয়ের লিংকের তালিকাকে এক ক্লিকেই অ্যাফিলিয়েট লিংকে রূপান্তর করুন। সব কিছু আপনার ব্রাউজারেই চলে।

আগে প্রোডাক্ট লিংক দরকার?

লিংকের তালিকা না থাকলে Firecrawl দিয়ে রকমারির category বা brand পেজ থেকে সব লিংক বের করে নিতে পারেন।

Firecrawl খুলুন ↗
Firecrawl দিয়ে লিংক সংগ্রহের নিয়ম
  1. firecrawl.dev-এ ফ্রি account খুলুন এবং Dashboard থেকে API key নিন (শুরু হয় fc- দিয়ে)।
  2. রকমারির category বা brand পেজে Map endpoint চালান (১ credit খরচ)।
  3. ফলাফল থেকে শুধু /product/ বা /book/ থাকা লিংকগুলো নিচে পেস্ট করুন।
curl https://api.firecrawl.dev/v2/map \ -H "Authorization: Bearer fc-your-key" \ -H "Content-Type: application/json" \ -d '{"url":"https://www.rokomari.com/category-brand/2355/Nivea/12692","search":"product"}'

1 আপনার অ্যাফিলিয়েট Token

এটি প্রমাণ করে লিংকগুলো আপনার নিজের অ্যাফিলিয়েট account থেকে তৈরি হচ্ছে।

Token কোথায় পাব?
  1. কম্পিউটারের Chrome-এ affiliate.rokomari.io-তে log in করুন।
  2. F12 চেপে Developer Tools খুলুন, তারপর Network ট্যাবে যান।
  3. Filter বক্সে createCustomURL লিখুন।
  4. Dashboard-এ একটি অ্যাফিলিয়েট লিংক generate করুন।
  5. Network-এ createCustomURL request-এ চাপুন, Headers ট্যাবে Authorization: Bearer eyJ... খুঁজুন।
  6. "Bearer " এর পরের পুরো অংশ কপি করে উপরের বক্সে পেস্ট করুন।

Token-এর মেয়াদ প্রায় এক সপ্তাহ। লিংক তৈরি হঠাৎ বন্ধ হলে নতুন token নিন।

🔒 Token শুধু আপনার browser থেকে সরাসরি রকমারির API কল করতে ব্যবহৃত হয়, কোথাও জমা হয় না।

লিংক পেস্ট করুন অথবা CSV / Excel / text ফাইল আপলোড করুন। অন্য লেখার সাথে মিশে থাকলেও লিংক আলাদা করে নেওয়া হবে।
