একসাথে অনেক অ্যাফিলিয়েট লিংক তৈরি করুন

রকমারির প্রোডাক্ট লিংকের তালিকাকে এক ক্লিকেই অ্যাফিলিয়েট লিংকে রূপান্তর করুন। সব কিছু আপনার ব্রাউজারেই চলে — আপনার token কখনো এই পেজ ছেড়ে যায় না।

আগে প্রোডাক্ট লিংক দরকার?

যদি আপনার কাছে এখনো লিংকের তালিকা না থাকে, Firecrawl একটি request-এই রকমারির যেকোনো category বা brand পেজ থেকে সব প্রোডাক্ট URL বের করে দিতে পারে।

Firecrawl খুলুন ↗
Firecrawl দিয়ে প্রোডাক্ট লিংক সংগ্রহ করবেন যেভাবে
  1. firecrawl.dev-এ একটি ফ্রি account খুলুন — ফ্রি tier-এ মাসে ১,০০০ credit পাওয়া যায়, যা এই কাজের জন্য যথেষ্ট।
  2. Dashboard থেকে নিজের API key নিন (শুরু হয় fc- দিয়ে)।
  3. রকমারির কোনো category বা brand পেজে Map endpoint ব্যবহার করুন — এটি সেই পেজের সব link এক request-এই ফেরত দেয় (মাত্র ১ credit খরচ হয়), পুরো পেজ scrape না করেই।
  4. ফলাফল থেকে শুধু /product/ থাকা link গুলো বেছে নিন — সেগুলোই নিচে পেস্ট করার জন্য।
curl https://api.firecrawl.dev/v2/map \ -H "Authorization: Bearer fc-your-key" \ -H "Content-Type: application/json" \ -d '{ "url": "https://www.rokomari.com/category-brand/2355/Nivea/12692", "search": "product" }'

অনেক পেজ থাকা কোনো পুরো category-র জন্য এর বদলে Crawl endpoint ব্যবহার করুন, সাথে includePaths: ["/product/*"] ও একটা page limit সেট করে দিন। মনে রাখবেন: Firecrawl অনেক anti-bot সুরক্ষা ভালোভাবে সামলাতে পারে, কিন্তু সব সময় ১০০% নিশ্চয়তা দেয় না — কোনো পেজ ব্যর্থ হলে আবার চেষ্টা করুন, অথবা R&D টিমের কাছে internal export চেয়ে দেখুন।

1 আপনার অ্যাফিলিয়েট Token

এটি প্রমাণ করে যে সত্যিই আপনার নিজের অ্যাফিলিয়েট account থেকেই লিংকগুলো তৈরি হচ্ছে। এটি শুধু এই পেজেই, লোকালি বসানো হয়।

Token কোথায় পাব?
  1. Chrome বা Firefox-এ affiliate.rokomari.io-তে log in করুন।
  2. F12 চাপুন (অথবা যেকোনো জায়গায় right-click করে Inspect করুন) — Developer Tools খুলবে, তারপর Network ট্যাবে যান।
  3. Network প্যানেলের উপরে filter বক্সে createCustomURL লিখুন।
  4. Dashboard-এ ফিরে গিয়ে স্বাভাবিকভাবে একটি অ্যাফিলিয়েট লিংক generate করুন — একটি প্রোডাক্ট লিংক পেস্ট করে Generate-এ ক্লিক করুন।
  5. Network প্যানেলে createCustomURL নামের একটি request দেখা যাবে। সেটাতে ক্লিক করুন।
  6. এর Headers ট্যাবে গিয়ে খুঁজুন Authorization: Bearer eyJ...
  7. "Bearer " শব্দটির পরের পুরো অংশটুকু কপি করে উপরের বক্সে পেস্ট করুন।

এই token-এর মেয়াদ প্রায় এক সপ্তাহ পর শেষ হয়ে যায়। নিচে লিংক তৈরি করা হঠাৎ বন্ধ হয়ে গেলে, একই নিয়মে এখানে ফিরে এসে একটি নতুন token নিন।

🔒 এই token শুধু আপনার browser থেকে সরাসরি রকমারির অ্যাফিলিয়েট API কল করতেই ব্যবহৃত হয়। এই ট্যাব বন্ধ করার পর এটি আর কোথাও থাকে না, এবং আমাদের কাছেও পাঠানো হয় না।
